# student-management-system
## 🚀 Technical Highlights

### 🤖 AI-Powered Attendance
- **Engine:** Face-api.js (SSD Mobilenet v1 & Face Landmark 68 Model).
- **Core Logic:** Real-time 128-bit vector embedding extraction for student verification.
- **Efficiency:** Client-side processing to minimize server latency and ensure privacy.

### ⚙️ Automation & Backend Engine
- **Background Jobs:** Node-cron integration for daily automated absenteeism tracking.
- **Messaging:** Logic-driven WhatsApp URL integration for instant parent alerts.
- **Storage:** Cloudinary integration for secure and optimized profile media management.

### 📊 Data Visualization & Analytics
- **Frontend Insights:** Recharts integration for visual fee tracking and attendance ratios.
- **Relational Logic:** Optimized MongoDB schemas for seamless data flow between Students, Fees, and Courses.

### 🎨 Design & Experience
- **Styling:** Tailwind CSS v4 for a modern, fluid Glassmorphism UI.
- **Animations:** Framer Motion for smooth transitions and interactive feedback.
